simple-crud-API is a full-stack web application built using Node.js, Express.js, MongoDB, and Mongoose that implements complete CRUD (Create, Read, Update, Delete) operations.

The application follows the MVC pattern and uses EJS for server-side rendering to dynamically generate HTML views from database data.

🛠 Tech Stack

Node.js – Runtime environment for executing JavaScript on the server.

Express.js – Web framework used for routing, middleware handling, and API development.

MongoDB – NoSQL database for storing application data in document format.

Mongoose – ODM (Object Data Modeling) library for schema definition and database interaction.

EJS – Templating engine for server-side rendering.

HTML & CSS – Frontend structure and styling.

⚙ Core Features

Create – Add new records to MongoDB using POST requests.

Read – Fetch and display all records from the database.

Update – Modify existing records using PUT/PATCH methods.

Delete – Remove records from the database using DELETE requests.

Schema Validation – Data validation handled through Mongoose schemas.

Server-Side Rendering – Dynamic content rendered using EJS templates.

RESTful Routing – Follows REST architecture principles.
